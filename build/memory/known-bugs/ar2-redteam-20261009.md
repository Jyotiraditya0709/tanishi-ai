## Still open (residuals, on purpose)

- **Same-user process.** The candidate's code and the attempt run as the caller's OS user. A program that sets out to
  rewrite both a fixture and `.arena/truth` (without naming `.arena` in a tool input), or to read the verifier
  process's memory or files, is not stopped. Closed only by a real sandbox / the Warden (W1).
- **Guessing.** Small answers can be guessed: `memory_recall` 1 in 24, `count_matching_files` about 1 in 15 when a
  `run_command` hides the count behind arithmetic (`echo $((3+4))`). A tool call aimed at the target is still needed.
- **`explain_concept`** is a code floor, not a grader: eight words of keyword salad still score 1.
- **`flaky_probe`** fails an honest answer that puts the failed first try and PROBE OK in one sentence.
- **Setup randomness reads `</dev/urandom`.** `test_setup_scripts_stay_inside_the_attempt_home` forbids absolute paths
  after whitespace; `<` directly before the path is not matched. It is a read of a device, not a write outside the
  home, so it is within the test's intent, but the regex is what lets it through.
