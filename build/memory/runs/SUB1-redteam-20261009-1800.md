# SUB1 · red-team round 2 · after-task answers

1. **What did we learn?** The round-1 secret fix reuses `events.redact()`, so SUB1 inherits its weaknesses: a quadratic
   regex (R1) and a text-only secret-key rule (R2). A fix that borrows another module's filter is only as safe as that filter.
2. **What failed, and why?** The comment in `events.py` says its patterns cannot backtrack quadratically; the first
   assigned-secret pattern does, because `[\w-]*` after the keyword is retried at each keyword. No test fed it repeated keywords.
3. **Which assumption was wrong?** That redacting before storage makes `save()` cheap and safe on any input. It is safe
   against leaks only for the shapes `redact` knows, and it is not bounded in time.
4. **What should the next agent know?** Fuzz any new text filter with repeated keywords and measure at 40 kB, not 40 bytes.
   Fix R1 in `events.py` (CS2's owner), and make `_without_secrets` use `events._scrub`'s secret-key rule (R2). B2 and B3 from
   round 1 are still waiting on a human ruling. I changed no product code; only tests and notes were added.
