# SUB1 · repair run 2 (human decisions on red-team rounds 1 and 2)

1. **What did we learn?** Making a regex quantifier possessive stops backtracking *within* one match attempt, not the
   number of attempts. `password[\w-]*+` still started a scan to the end of the run at each of 40 000 "password"s, so
   it stayed quadratic and only halved. What made `events.redact()` linear was choosing *where a match may start*:
   only where a name starts (`(?<![\w-])`), with the secret word found by a lookahead (atomic in Python) and the name
   eaten possessively. Every keyword is made of `[\w-]` characters, so it always lies inside the name before `:`/`=`,
   and the output is unchanged (every existing redact assertion passes). 320 kB now redacts in milliseconds.
2. **What failed, and why?** R3 (refuse a `task_id` that `redact()` would change). I built it and it failed
   `test_r2_secret_in_task_id_is_stored_in_plaintext`, which calls `save()` without `pytest.raises` and wants it to
   succeed. The test wins, so the check is out and the conflict, with two ways to settle it, is in
   `open-problems/SUB1-repair-conflicts.md`.
3. **Which assumption was wrong?** That the human's fixes and the red-team tests always agree. For R3 they do not:
   the report's own "smallest fix" (ValueError) contradicts its test. Also wrong, from round 1: that hiding non-text
   values under secret keys would cost too much. The human ruled that a leaked nested credential is worse than a
   hidden counter, so `{"token": 5}` is now `"[REDACTED]"`.
4. **What should the next agent know?** Decision 0014 is now `decisions/0017-substrate-state.md`. Step ids must be
   unique and non-blank. Statuses must be printable ASCII with no capitals and no blanks (`"waiting:tool"` is fine,
   `"in progress"` is not). Any value under a secret-named key (`token`, `auth`, `password`…) comes back as
   `"[REDACTED]"`, so name counters `n_tokens`, not `token` or `token_count`. Error messages name dict keys by position
   (`working[key #0]`). `load()` of an id with a lone surrogate raises LookupError. `events.py` (CS2's file) changed
   on the human's instruction; `tests/core_state/test_redact_speed.py` pins the speed. The red-team tests had no xfail
   marks to remove; they failed outright. SUB1 produces no intelligence, so there is no benchmark.
