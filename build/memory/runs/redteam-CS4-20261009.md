## Held (tried, no break)

Raw `'USER'` owner never sorts above a real user goal (G3). Delete of a parent with children is refused under FK (G5).
`INSERT OR REPLACE` cannot smuggle a cycle (G6). Reparent to NULL leaves exact ancestor rows, and a later cycle is still
rejected (G7). Eight threads on first use install the triggers once (G9). Two concurrent opposite reparents never form a
2-cycle (G10). A user goal under a tanishi parent still sorts first (G11).
