# OBS1 · implementer run, 2026-10-10

1. **What did we learn?** Linking spans to events needs a hook inside `emit()`: `brain.py`, `registry.py`,
   `beliefs.py` and `predictions.py` all `from ... import emit`, so wrapping `events.emit` from outside would miss
   them. A post-commit listener list (fail-open) is a five-line change and keeps CS2's semantics intact.
2. **What failed, and why?** Nothing in the exam; all 25 tests passed on the first run. Ruff flagged every blind
   `except Exception`; fail-open code needs them, so each carries a `noqa: BLE001` with the reason, as in `registry.py`.
3. **Which assumption was wrong?** That the exam's A4 ("event ids captured automatically") could be met without
   touching CS2's file. It cannot, short of monkeypatching every importer.
4. **What should the next agent know?** Format and hook are in decision 0021, limits in
   `known-bugs/obs1-trace-limits.md`. To trace a real task, open `span("think", model=...)` in `think()` inside its
   `task_scope` and call `s.set(tokens_in=..., tokens_out=...)` after the response; tool calls then link by
   themselves via the `tool_call` event. CLI output keeps one line per span, indented two spaces per level.
