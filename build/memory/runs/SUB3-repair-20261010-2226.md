Fixed the five red-team breaks on the human's decisions, in the order given (B2, B4, B1, B3, B5), one commit each,
then added `RouteContext.input_tokens`. Removed the `BREAK` mark from each red-team test as its fix landed: all 9 now

Own tests in `test_router_impl.py` grew from 15 to 22 functions (B2 event flag, `model_spend` events, `aroute`, byte

updated. The decision file was already at `decisions/0020-model-router.md`, so no rename was needed.

1. **What did we learn?** A privacy flag has to be tested by identity (`is not False`), not by truthiness. Otherwise
   any unset value fails open. The other fixes were small. Most of the work was choosing what each one does at
   its edges: whether `report_spend` raises once the call is paid (it does not: it warns and records
   `recorded: false`), whether a gate-off or local report writes an event (no: there is no report), and what
   `input_tokens` must reject (bools, floats, negatives).
2. **What failed, and why?** Nothing in the tests failed. Two things nearly did: (a) `text.encode("utf-8")` raises on a
   lone surrogate, which would crash `route()` before its event was written. I used `surrogatepass` (same count for
   valid text) and added a test. (b) ruff's import sorter would not accept a trailing comment on the merged
   `from tanishi.config import models, routing` line, so the comment moved to the line that uses it.
3. **Which assumption was wrong?** That the full suite would reach 0 xfailed once SUB3 was fixed. SUB3 now has 0
   xfails, but 5 xfails remain in other nodes' red-team files (CS2 events, CS3 beliefs, CS6 genome x3). They are
   outside this card, so I did not touch them.
4. **What should the next agent know?** Async callers (the loop, the brain) must call `router.aroute()`, never
   `route()`. Fill `RouteContext.input_tokens` with the size of the whole prompt, or the spend check sees only the
   step text. Pass `step_id=` to `report_spend()` so the `model_spend` event ties back to the step. Fake the Warden by
   patching `tanishi.guard.client.check`. The legacy brain still has the LOCAL_FIRST bug until a wiring node calls
   the router.
